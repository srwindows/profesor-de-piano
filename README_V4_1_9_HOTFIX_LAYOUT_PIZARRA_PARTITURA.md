# Profesor de Piano IA — v4.1.9 lite hotfix layout pizarra/partitura

Cambios aplicados sobre v4.1.8:

- La pizarra/partitura pasa a ser la zona prioritaria de la pantalla.
- El piano interactivo queda debajo del área de clase, para no empujar la pizarra hacia abajo.
- La pantalla de lectura de partitura se reorganiza en proporción 3/4 + 1/4:
  - izquierda: pizarra/partitura, explicación y controles;
  - derecha: puntos de clase, progreso y ejercicios.
- El metrónomo de lectura se compacta para no ocupar tanto espacio vertical.
- La clave de Sol y la clave de Fa se redibujan con trazos vectoriales más reconocibles.
- Se mantiene la lógica existente de lectura por puntos, retos, MIDI didáctico, pizarra interactiva y botones ya conectados.

Nota de entrega ligera:

- La carpeta `voices/` no se incluye en este ZIP para evitar exceso de peso. Debe copiarse manualmente desde tu carpeta de voces habitual en la raíz del proyecto.
