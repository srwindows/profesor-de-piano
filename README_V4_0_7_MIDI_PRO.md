# Profesor de Piano v4.0.7 Lite — Motor MIDI Pro

## Uso

Ejecuta:

```bash
python3 main.py
```

El profesor empieza a registrar diagnósticos más profesionales cuando el alumno toca en:

- teclado MIDI;
- piano virtual;
- retos de pizarra;
- retos con pulso;
- ejercicios de acorde.

## Archivo clave

```text
app/core/analisis_midi_pro.py
```

## Siguiente paso lógico

Mostrar un panel visual de diagnóstico Pro para el profesor/alumno:
nota, pulso, velocity, reacción, simultaneidad y recomendación.
