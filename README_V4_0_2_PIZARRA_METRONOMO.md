# Profesor de Piano v4.0.2 Lite — Pizarra + metrónomo

## Uso

1. Abre `Partitura`.
2. Pulsa `Leer punto actual`.
3. Pulsa `Tocar con pulso`.
4. Espera el clic.
5. Toca la nota marcada en el piano virtual o en tu teclado MIDI.

## Objetivo

Pasar de tocar notas correctas a tocar notas correctas **en pulso**.
