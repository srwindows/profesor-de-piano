# Profesor de Piano v3.9.5 Lite — Pizarra con capas y piano

## Uso

```text
Partitura → Leer punto actual
```

La pizarra ahora permite activar u ocultar capas:

```text
Claves, Notas, DO central, Manos, Figuras, Pulso, Digitación, Puntero
```

## Relación con el piano

Cuando la pizarra explica una nota importante, el piano virtual puede resaltarla sin emitir sonido.

Esto empieza a unir:

```text
profesor → pizarra → piano → alumno
```
