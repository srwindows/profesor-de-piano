# Profesor de Piano v3.9.8 Lite — MIDI del alumno

## Uso

1. Conecta tu teclado MIDI desde Configuración.
2. Abre `Partitura`.
3. Pulsa `Leer punto actual`.
4. Usa `Tocar en piano` o `Tocar secuencia`.
5. Toca en tu teclado MIDI externo.

El profesor comprobará la nota o secuencia tocada.

## Objetivo

Preparar la primera lectura real del alumno:

```text
leer pentagrama → localizar nota → tocar en teclado MIDI → recibir corrección
```
