# Profesor de Piano v3.9.4 Lite — Pizarra sincronizada

## Objetivo

Que el profesor hable exactamente de lo que se está dibujando en la pizarra.

## Uso

```text
Partitura → Leer punto actual
```

Después usa:

```text
← paso
paso →
Mostrar ejemplo
Ver texto
```

Cada paso activa una explicación sincronizada con el elemento visible.

## Ejemplo

- Paso de clave de Sol: explica por qué se llama clave de Sol.
- Paso de clave de Fa: explica por qué se llama clave de Fa.
- Paso de Do central: explica que queda entre ambos pentagramas.
- Paso de figuras: explica duración.
- Paso de pulso: explica conteo.
