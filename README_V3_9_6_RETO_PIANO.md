# Profesor de Piano v3.9.6 Lite — Reto de piano desde pizarra

## Uso

1. Abrir `Partitura`.
2. Pulsar `Leer punto actual`.
3. Avanzar con `paso →`.
4. Pulsar `Tocar en piano`.
5. Tocar en el piano virtual la nota que pide el profesor.

## Objetivo

Cerrar el ciclo docente:

```text
ver → entender → tocar → comprobar
```
