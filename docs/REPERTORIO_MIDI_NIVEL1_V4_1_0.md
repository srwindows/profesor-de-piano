# Repertorio MIDI Nivel 1 — v4.1.0

## Piezas

1. Técnica cinco dedos en DO.
2. Cumpleaños feliz simplificado.
3. Oda a la alegría reducida.
4. Frère Jacques simplificado.
5. Twinkle simplificado.
6. Vals didáctico del profesor.

## Uso propuesto

- Escuchar MIDI.
- Tocar mano derecha.
- Tocar mano izquierda.
- Unir ambas manos.
- Activar Diagnóstico Pro.
- Repetir con metrónomo lento.

## Política

Los archivos son pequeños y quedan dentro del ZIP.
No se incluyen voces ni modelos pesados.
