# v4.0.0 — Colecciones preparadas

## Objetivo

Dejar preparada la estructura completa del curso para no improvisar rutas, carpetas ni enlaces internos en cada versión.

## Qué queda cerrado

- Nivel 0 cerrado con 20 clases.
- Evaluación final Nivel 0 con 20 preguntas.
- Estructura de Nivel 1 preparada con 30 clases.
- Estructuras base de niveles posteriores preparadas.
- Carpetas de teoría, partituras, MIDI, audio de referencia, vídeo de referencia y documentación.
- Catálogo maestro de colecciones.
