# v2.5.7 — Lectura guiada por puntos

- Se corrige el fallo de lectura provocado por la falta de `import re`.
- Todas las pestañas integradas reciben un botón superior: `Leer título/resumen de la pestaña`.
- El botón inferior pasa a ser `Leer punto actual`.
- Junto a ese botón se añaden flechas `←` y `→`.
- Se añade `✓ Punto superado`.
- La flecha de avance solo se desbloquea cuando el punto actual se marca como superado.
- El profesor actualiza el panel derecho con el punto que está explicando.
