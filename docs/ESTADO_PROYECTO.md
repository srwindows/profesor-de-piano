# Estado del proyecto v1.7.3

La versión 1.7.3 mantiene la interfaz limpia y pedagógica, y corrige la voz del avatar.

## Cambios principales

- Voz robótica eliminada del flujo del programa.
- El avatar usa solo Piper TTS.
- Configuración persistente de modelos de voz chica/chico.
- Diagnóstico de voz actualizado.
- Script para localizar voces Piper ya descargadas.
- Modo clase, piano de 88 teclas, MIDI, cámara, audio y progreso siguen integrados.

## Punto pendiente

Los modelos Piper `.onnx` no se incluyen en el ZIP. Deben descargarse o seleccionarse desde Configuración.
