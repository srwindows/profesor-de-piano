# Nota sobre Hanon y el método propio del Nivel 1

Charles-Louis Hanon es un autor del siglo XIX y existen ediciones antiguas de dominio público. Aun así, el proyecto no debe depender de copiar una edición moderna concreta.

## Decisión del proyecto

El Nivel 1 se construirá como método técnico propio:

- patrones originales;
- explicaciones propias;
- integración con pizarra;
- integración con metrónomo;
- integración con MIDI;
- evaluación paso a paso.

## Enfoque técnico

El objetivo pedagógico será trabajar regularidad, igualdad de dedos, relajación, control de pulso e independencia inicial, pero con material creado para este programa.
