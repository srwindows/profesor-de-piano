# Cambios v1.9.2 — Lecciones guiadas y progreso del alumno

Esta versión convierte la teoría visual del Nivel 0 en una clase guiada real.

## Añadido

- Sistema de lecciones por JSON en `data/lecciones_nivel_0.json`.
- Progreso pedagógico independiente en `data/progreso_alumno.json`.
- Panel de clase guiada en la pantalla de Teoría:
  - objetivo de la lección;
  - explicación del profesor;
  - ejemplo práctico;
  - pregunta de comprobación;
  - botón para marcar como aprendida;
  - avance bloqueado hasta comprobar o confirmar comprensión.
- Mini evaluación de Nivel 0, desbloqueada cuando se superan todas las lecciones.
- Botón para abrir directamente la imagen de la lección actual.
- Botón para leer la lección actual con el avatar.

## Lecciones iniciales de Nivel 0

1. Postura al piano: incorrecto y correcto.
2. Postura al piano: guía paso a paso.
3. Postura correcta de la mano.
4. Digitación 1–5.
5. Patrón del teclado.
6. Teclas blancas: DO RE MI FA SOL LA SI.
