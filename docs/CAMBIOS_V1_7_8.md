# Cambios v1.7.8

- Añadidos botones visibles **Pausa voz** y **Stop voz** en la pantalla principal.
- Añadidos controles **Pausa / Reanudar** y **Stop voz** en Configuración > Avatar y voz.
- La pausa de voz funciona con reproductores externos de Linux mediante SIGSTOP/SIGCONT y también con sounddevice por bloques.
- El piano interactivo de 88 teclas queda siempre visible en la parte superior del área de estudio.
- Altura inicial del piano aumentada a 150 px.
- Se mantiene la regla de no usar botones rojos.
