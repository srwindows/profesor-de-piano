## Ruta de trabajo

A partir de esta versión no hay que crear carpetas desde cero. Cada nueva clase deberá completar:

```text
data/colecciones/<nivel>/clases.json
assets/teoria/<nivel>/
assets/partituras/<nivel>/
assets/midi/<nivel>/
docs/curriculo/<nivel>/
```

## Nivel 1

El Nivel 1 queda preparado como método técnico propio inspirado en técnica progresiva, sin copiar una edición moderna concreta.
