# Profesor de Piano v4.0.8 Lite — Entradas Pro

## Entradas del profesor

```text
MIDI: activo continuo
Historial: activo continuo
Cámara: bajo demanda
Sonido: bajo demanda
```

## Uso

En la pestaña `Entradas Pro`:

- `Profesor pide cámara`: solicita al alumno activar cámara para postura/manos.
- `Profesor pide escucha`: solicita activar micrófono para sonido real.
- `Activar escucha`: activa análisis ligero de nivel.
- `Detener escucha`: detiene micrófono.

No se graba audio ni vídeo por defecto.
