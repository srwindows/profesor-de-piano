# Profesor de Piano v4.0.6 Lite — Historial pedagógico

## Idea

El profesor ya empieza a guardar un expediente vivo del alumno.

## Uso

Ejecuta:

```bash
python3 main.py
```

Cuando el alumno avance, conteste, toque en el piano virtual o entre por MIDI, se irán creando datos en:

```text
data/alumnos/
```

## Siguiente paso lógico

Conectar este historial al motor Pro MIDI avanzado para evaluar acordes, simultaneidad, velocity, reacción y pulso con más precisión.
