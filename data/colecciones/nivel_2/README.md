# Nivel 2 — Lectura aplicada y manos coordinadas

Estado: **completo funcional**  
Versión: `4.1.15-lite-hotfix-niveles-1-2-completos`

Este nivel contiene 30 clases completas. Cada clase incluye:

- clase teórica;
- pizarra/pentagrama con secuencia docente;
- archivo MIDI didáctico generado;
- partitura MusicXML generada;
- 4 ejercicios asociados;
- examen final de clase;
- enlace a la siguiente clase;
- examen global del nivel.

Regla didáctica: teoría → ejercicios asociados → examen final de clase → siguiente clase. La última clase desbloquea el examen global del nivel.
