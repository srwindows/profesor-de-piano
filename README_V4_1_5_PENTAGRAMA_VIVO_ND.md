# Profesor de Piano v4.1.5 Lite — Pentagrama vivo ND

## Objetivo

El pentagrama se sincroniza con la nota activa del archivo MIDI didáctico.

## Uso

```bash
python3 main.py
```

Abre:

```text
MIDI Didáctico
```

Pulsa:

```text
Clase 1 Nivel 1
```

o carga una pieza del repertorio y usa:

```text
Escuchar guía
Practicar
Examen
```

La nota activa se resaltará en el pentagrama ND.
