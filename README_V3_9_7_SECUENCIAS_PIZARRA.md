# Profesor de Piano v3.9.7 Lite — Secuencias guiadas desde pizarra

## Uso

1. Abrir `Partitura`.
2. Pulsar `Leer punto actual`.
3. Usar `paso →` hasta una explicación con notas.
4. Pulsar `Tocar secuencia`.
5. Tocar las notas en el orden que pide el profesor.

## Objetivo

Pasar de nota aislada a frase pequeña:

```text
concepto → nota → secuencia → ejercicio musical
```
