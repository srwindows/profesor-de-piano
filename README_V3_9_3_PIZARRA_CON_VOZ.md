# Profesor de Piano v3.9.3 Lite — Pizarra con voz

## Uso

1. Abrir `Partitura`.
2. Pulsar `Leer punto actual`.
3. Usar los botones de la pizarra:

```text
← paso
paso →
Mostrar ejemplo
Ver texto
```

El profesor leerá cada paso o ejemplo.

## Motivo

La pizarra debe funcionar como una clase real: el profesor explica, señala, cambia de paso y vuelve a explicar si hace falta.
