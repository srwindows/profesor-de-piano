# Profesor de Piano v3.8.0 Lite — Retos de comprensión

Esta versión mantiene la rama Lite estable y añade una mejora pedagógica importante:

```text
No se avanza solo por pulsar.
Primero hay que superar un reto breve.
```

## Flujo de clase

```text
Leer punto actual → Comprobar → Responder reto → Avanzar
```

## Ventajas

- No usa IA pesada.
- No depende de internet.
- No carga modelos.
- Funciona con reglas rápidas.
- Mejora la sensación de profesor real.
- Bloquea el avance si el alumno falla.

## Ejecución

```bash
python3 main.py
```

## Voces

La carpeta `voices` sigue fuera del ZIP y debe añadirse manualmente.
